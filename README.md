# Алгоритмический мини-пакет

Устанавливаемый Python-пакет с алгоритмами, стеком, генераторами тестовых наборов и benchmark

## Возможности

- Итеративное и рекурсивное вычисление чисел Фибоначчи
- Сортировка пузырьком (Bubble Sort) и сортировка слиянием (Merge Sort)
- Стек с операциями добавления, извлечения и просмотра вершины
- Генерация пяти типов наборов данных для тестирования
- Измерение времени сортировок и сохранение результатов в CSV

## Основные классы и функции

### fibonacci.py

- `fibonacci_iter` — итеративное вычисление числа Фибоначчи
- `fibonacci_recursion` — рекурсивное вычисление числа Фибоначчи

### sorting.py

- `bubble_sort` — сортировка пузырьком с досрочным завершением при отсутствии обменов
- `merge_sort` — рекурсивная сортировка слиянием
- `merge` — объединение двух отсортированных списков

### stack.py

- `Stack` — стек с методами `push`, `pop`, `peek`, `__len__`, `__bool__`

### generators.py

- `random_generator` — случайные целые числа
- `sorted_generator` — возрастающая последовательность
- `reverse_generator` — убывающая последовательность
- `duplicates_generator` — набор с большим количеством повторений
- `nearly_sorted_generator` — почти отсортированный набор

### benchmark.py и __main__.py

- `measure_sort` — медиана времени сортировки за несколько запусков
- `run_benchmark` — сравнение сортировок на разных наборах и размерах
- `save_results` — запись результатов в `results.csv`
- `__main__.py` — запуск benchmark командой `python -m algo_lab`

## Особенности реализации

- Сортировки возвращают новый список и не изменяют исходный; встроенные `sort()` и `sorted()` в их реализации не используются
- Генераторы со случайностью принимают `seed` для воспроизводимости результатов
- Некорректные типы аргументов вызывают `TypeError`, отрицательные размеры — `ValueError`
- `pop` и `peek` пустого стека вызывают `IndexError`; стек работает по принципу LIFO
- Рекурсивный Fibonacci медленно работает при больших `n` и ограничен глубиной рекурсии Python (`RecursionError`)

## Сложность алгоритмов

| Алгоритм | Время | Дополнительная память |
|---|---|---|
| Fibonacci (итеративно) | O(n) | O(1) |
| Fibonacci (рекурсивно) | O(2ⁿ) | O(n) |
| Bubble Sort | O(n²), лучший случай O(n) | O(n) |
| Merge Sort | O(n log n) | O(n) |
| Стек: `push`, `pop`, `peek`, `len`, `bool` | O(1) | O(1) на операцию |
| Генераторы наборов | O(n) | O(n) |

Оценки для Fibonacci приведены по числу арифметических операций без учёта стоимости работы с большими целыми числами

## Benchmark

Измерения выполнены на пяти типах наборов: случайном, отсортированном, обратном, с повторами и почти отсортированном. Размеры различаются из-за квадратичной сложности Bubble Sort:

- **Bubble Sort:** 100, 1 000 и 10 000 элементов
- **Merge Sort:** 10 000, 100 000 и 1 000 000 элементов

Каждая комбинация измеряется **5 раз**, результат — медиана времени. Генерация данных и создание независимой копии списка не входят в замер. Полные результаты находятся в `results.csv` (время в секундах).

Результаты для случайных наборов:

| Алгоритм | Размер | Время, с |
|---|---:|---:|
| Bubble Sort | 100 | 0,000295 |
| Bubble Sort | 1 000 | 0,034008 |
| Bubble Sort | 10 000 | 3,664092 |
| Merge Sort | 10 000 | 0,027917 |
| Merge Sort | 100 000 | 0,320310 |
| Merge Sort | 1 000 000 | 4,020896 |

На общем размере **10 000** элементов Merge Sort на случайном наборе примерно в **131 раз быстрее** Bubble Sort. Результаты соответствуют ожидаемым сложностям O(n²) и O(n log n). На уже отсортированных данных Bubble Sort ускоряется благодаря досрочному завершению

## Установка зависимостей

Требуются Python 3.12 или новее и `uv`.

```bash
uv sync
```

## Запуск benchmark

```bash
uv run python -m algo_lab
```

Результаты записываются в `results.csv` в текущей рабочей папке

## Тестирование

```bash
uv run pytest -v
```
